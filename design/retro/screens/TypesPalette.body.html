File types

The card header and the stack peeks take the accent of the file's type, so a mixed review deck reads at a glance. Text on every accent is the ink colour (5.2:1 or better).

[[i:layers]]How it applies
  • Header fills with the type accent, ink text.
  • Peeks behind the card use the type of the next files in the queue.
  • Unknown extensions fall back to sand, never a random hue.
[[i:check]]One accent per type. React is split from plain TS because component files are the most common review.
[[i:minus]]Status stays separate. Added, modified, renamed and deleted keep their dot and chip colours; type only drives the card.
[[i:arrow-right-left]]Light and dark pair. Dark steps are lifted a little so the ink still holds 6.9:1 or better.
