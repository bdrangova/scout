Full flow / proposed behaviour

Design plan, not implemented backend behaviour. The wireframe only simulates local review interactions.

1. Start in Claude / Codex

Ask to review a PR. Use the default review skill, replace it, or chain skills in that session. Scout receives the report; it does not run or choose reviewers.

PR + pinned base/head → reviewer(s) → merged report

2. Generate + verify

Capture every changed file. Normalize findings, keep skill provenance, merge true duplicates. For critical/high/medium issues attempt reproduction, record numbered steps and expected/observed results, and attach screenshots to specific steps.

Blocked or non-visual reproduction is explicit. Never substitute a placeholder for proof.

3. Open the existing Files shell

Same session rail, full changed-file tree, commit scope, Swipe/Grid and diff card. Zero-finding files remain reviewable. File counts track file verdicts; comment counts track proposed-comment decisions.

4. Review files + inline comments

Approve/reject/comment on the file. Separately edit, approve, reject or leave a reviewer note on each proposed comment. Click a line (Shift-click for a range) to author your own comment. Reproduction + screenshots sit below the diff, linked by issue ID.

File approval never approves suggested comments. File rejection never discards accepted suggestions. Editing an accepted suggestion requires approval again.

5. Prepare a summary

Show file verdicts, your added comments, and only approved proposed comments, including edited wording and evidence limitations. Pending/rejected suggestions are excluded. Unadded drafts remain visible as a warning.

File rejection needs a reason, following the existing Files pattern. Partial reviews may be copied with the remaining counts shown.

6. Copy / continue

Copy Markdown with paths, side + lines, severity, reproduction and usable evidence references. No GitHub posting in v1. Snapshot the export for later traceability.

New commits mark changed file verdicts and affected anchors stale; re-review before exporting them. A new report preserves decisions only for unchanged finding content and evidence.
